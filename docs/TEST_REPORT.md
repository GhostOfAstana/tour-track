# Отчёт проверок

Дата: **7 ноября 2026 года**. Среда: Linux amd64, существующий Go 1.26.8. Новые программы на компьютере не устанавливались. Основные проверки выполнены в предоставленной рабочей среде; облачный CI также выполнен на GitHub Actions для Go 1.24 и Go 1.26.

## Выполнено

- `go test ./...` — все пакеты проходят.
- `go test -race -cover ./...` — гонок на выполненных путях не обнаружено.
- `go vet ./...` — замечаний нет.
- `gofmt -l .` — список пуст.
- `node --check internal/web/static/app.js` — синтаксис корректен; Node нужен только для этой дополнительной проверки, не для приложения.
- `go list -m all` — только модуль `tour-track`, сторонних Go-модулей нет.
- `go build -trimpath` — исполняемый файл собран.
- Fuzz Score: 10 секунд, **625 118** входов, ошибок нет.
- Fuzz Analyze: 10 секунд, **538 397** входов, ошибок нет. Дополнительные короткие прогоны при разработке также прошли.
- Нагрузка: **1500 настоящих HTTP-запросов, 32 параллельных работника**, 14 операций, зависшее обновление с последующим отказом источника. Ответы корректны, полный каталог сохранился, сервер продолжил работать.
- Архив: 52 согласованных ID во всех четырёх частях; исходные Queen/Foo Fighters/Gorillaz/Travis Scott проверены отдельно.
- Изображения: 52 локальных JPEG/PNG, проверка декодирования, атрибуции, лицензий и SHA-256; суммарно **4 482 101 байт**.
- Реальный запуск бинарного файла: проверены главная, все 52 страницы артистов, все 52 изображения, CSS/JS, health/readiness, HEAD, 404/405 и фоновое неуспешное обновление без потери каталога; завершение через SIGTERM.

Тесты сети используют `httptest`, фиксированные часы, управляемые ошибки и каналы. Они не зависят от внешнего API. Проверяются границы классов, точный пример 40/Established, Rising Star и ровно +50%, нулевой стаж, переполнение, повреждённые даты, будущее, дубли, тайм-аут, несогласованные ID, повреждённый/слишком большой JSON, отказ HTTP, объединение кликов, cooldown, отмена, XSS, CSRF, неверные методы, ошибки шаблонов, восстановление после паники и тела POST без объявленной длины.

## Внешние ограничения

Исходный API 7 ноября 2026 года возвращал 404. Работа с живыми актуальными данными не подтверждена; сайт явно показывает исторический резерв. Время архива — дата коммита, а не неизвестная дата исходной выгрузки API.

Проверены 52 карточки и загрузка всех 52 фотографий после прокрутки, отправка формы поиска, переход к Queen и все семь участников, Established, нажатие обновления, состояние ожидания и понятная ошибка API с возвратом активной кнопки и сохранением каталога. Поиск Queen также находит Scorpions: в его локациях есть queenstown, что соответствует поиску по местам. Необработанных исключений JavaScript — 0.
