# Карта требований и сценарий аудита

Этот документ сопоставляет приложенное ТЗ `tour-track__ts.md` с реализацией. Он не подменяет результаты внешней проверки и не обещает отсутствие любых возможных ошибок.

## Бонусы

| Бонус | Реализация и проверка |
| --- | --- |
| Rising Star | `activity.IsRisingStar`, `activity.Analyze`, бейджи обоих шаблонов. Среднее 4/год и недавнее 7/год → да; 5/год → нет; ровно 6/год → нет. `TestRisingStar` |
| Асинхронные события | `POST /api/refresh` ставит задание в канал ёмкостью 1; отдельная горутина Store.Run обрабатывает его. Клиент опрашивает статус. Четыре upstream GET выполняются параллельно через горутины и канал |
| Публичный DNS | Конфигурация Render подготовлена. Фактический адрес и состояние публикации фиксируются отдельно в TEST_REPORT; существование YAML не означает успешного размещения |
| Дополнительное качество | Источник и суммы архива, запуск при отказе API, объяснимый расчёт, доступность, мобильный интерфейс, поиск/фильтры/сортировка, JSON API, race/fuzz/параллельная нагрузка |

## Расхождение ТЗ с историческими данными

В списке аудитора указано `sao_paulo-brasil`. В проверенном архиве API и двух независимых копиях записано `sao_paulo-brazil`. Приложение сохраняет исходный `sao_paulo-brazil` и поясняет альтернативное написание. В подсчёте уникальных стран `brasil` и `brazil` объединяются в одну Бразилию. Изменять исходную строку ради буквального совпадения с опечаткой означало бы искажать источник.

Исторический источник содержит собственные написания имён: например `John Daecon`. Они сохраняются, даже если реальное имя в других источниках пишется иначе. Каталог представляет данные API, а не исправленный музыкальный справочник.

## Короткий ручной прогон

1. Запустить `go run .`; увидеть 52 карточки и предупреждение о резерве, если API не работает.
2. Проверить Queen, Gorillaz, Travis Scott и Foo Fighters через поиск.
3. Открыть артиста и вручную пересчитать баллы из отображённых чисел.
4. Выбрать метку, сортировку, пустой результат поиска и сбросить фильтры.
5. Нажать обновление несколько раз; убедиться, что ошибки API показываются, каталог остаётся доступен.
6. Проверить 404 на неизвестном адресе, 405 на `POST /`, JSON `/api/status`, отсутствие тела `HEAD /`.
7. Выполнить тесты и сверить фактический отчёт. Старые даты не должны автоматически получать Rising Star только ради демонстрации: положительный пример есть в воспроизводимом unit-тесте.

## Ограничения обещания «никогда не падает»

Проверены воспроизводимые отказы сети, данных и обработчиков. Ошибки запуска (занятый порт, неверные настройки) завершают процесс с понятным сообщением. Исчерпание памяти всей ОС, SIGKILL, отключение электричества, лимиты провайдера и недоступность DNS находятся вне управления программы. Для круглосуточной эксплуатации нужны мониторинг и автоматический перезапуск средствами хостинга.
