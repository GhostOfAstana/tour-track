# Как пользоваться tour-track

tour-track — каталог артистов с гастрольной географией и объяснимой оценкой активности. Страницы показывают сведения источника, а не обещание будущих концертов: в API есть исторические даты. Здесь нет продажи билетов или автоматического подтверждения актуальности афиши.

## Найти артиста

На главной странице введите имя артиста, название группы, участника или часть исходного названия локации. Например: `Queen`, `Freddie`, `london` или `usa`. Поиск также учитывает год основания и дату первого альбома. Регистр букв значения не имеет. Названия стран в исходных данных обычно английские; русский перевод страны в поиск не подставляется автоматически.

Нажмите «Найти» или Enter. Поиск отправляет обычный GET-запрос: адрес с условиями можно сохранить в закладки или передать другому человеку. Пустое поле показывает всех артистов, подходящих под остальные фильтры. Если ничего не найдено, страница предложит убрать ограничения.

Фильтр «Активность» оставляет артистов с выбранной меткой: `Emerging`, `Active`, `Established`, `Legendary` или дополнительной `Rising Star`. Последняя может сочетаться с любой основной меткой. Порядок «По активности» показывает больший балл первым, «По году основания» — более поздний год первым, «По имени» — имена в алфавитном порядке. Для возврата к полному каталогу нажмите «Сбросить фильтры».

## Открыть карточку

Нажмите на изображение, имя или любую часть карточки. С клавиатуры перейдите к карточке клавишей Tab и нажмите Enter.

Страница артиста показывает:

- название, изображение, год начала деятельности и исходную дату первого альбома;
- участников в написании источника;
- основную метку активности и дополнительную `Rising Star`, если правило выполнено;
- числовые показатели и каждый член формулы;
- таблицу связей: место концерта и соответствующие ему даты из `relation`;
- отдельные исходные списки `locations` и `dates`, а также страны, использованные в расчёте.

Исходные локации и даты намеренно сохранены без перевода и исправления написания. Например, подчёркивание в `sao_paulo-brasil` и звёздочка перед датой остаются видны. Это помогает сопоставить интерфейс с ответом API. Страны для расчёта выделяются и нормализуются отдельно.

Чтобы вернуться в каталог, используйте «К каталогу артистов» или название tour-track вверху страницы.

## Прочитать оценку

Формула: `страны × 2 + даты × 3 + min(10, годы карьеры / 5)`. Годы делятся на 5 нацело. Продолжительность карьеры рассчитывается по текущему году при каждом запросе. Оценка описывает доступные гастрольные данные; она не измеряет качество музыки или популярность.

| Баллы | Основная метка |
| --- | --- |
| 0–10 | Emerging |
| 11–25 | Active |
| 26–40 | Established |
| 41 и больше | Legendary |

`Rising Star` появляется, если среднее число концертов за последние два года строго больше среднего за всю карьеру в 1,5 раза. Последние два года — промежуток от соответствующей календарной даты два года назад до текущего дня включительно. Будущие и нераспознанные даты в этот промежуток не включаются. При нулевой продолжительности карьеры метка не назначается. У старого набора данных может не быть ни одного недавнего концерта — отсутствие метки в таком случае корректно.

## Обновить данные

При включённом JavaScript вверху страницы появляется кнопка «Обновить данные». Она отправляет POST-запрос. Сервер ставит обновление в очередь, а браузер проверяет его результат. Пока четыре раздела API загружаются, каталог остаётся доступен. После успешного обновления страница перезагружается с прежним адресом, поэтому фильтры сохраняются.

Повторные нажатия во время работы блокируются. Если сервер ограничил частоту запросов, источник недоступен, соединение оборвалось или ожидание затянулось, рядом с кнопкой появляется сообщение. После ошибки кнопку можно использовать снова, учитывая указанную паузу. Ошибка обновления не удаляет предыдущий полный каталог.

Без JavaScript поиск, фильтры, сортировка, карточки и переходы между страницами работают. Кнопка фонового обновления скрыта; сервер всё равно обновляет каталог по своему расписанию.

## Если источник не работает

Жёлтое предупреждение «Свежие данные API не подтверждены» означает, что страница показывает сохранённую копию. При первом запуске это может быть встроенный резервный каталог. Дата на странице — время сохранённого каталога, а не доказательство нового успешного ответа API. Например, HTTP 404 от внешнего API не превращается в пустую афишу и не выдаётся за успешную загрузку: посетитель видит резервные сведения с предупреждением.

Если сохранённых данных вообще нет, сервер возвращает страницу ошибки с HTTP 503 и предложением повторить попытку позже. Неизвестный адрес или номер артиста возвращает понятную страницу HTTP 404 со ссылкой на главную. Эти ответы не означают падение сервера.

Изображения загружаются с внешнего адреса из API. Если изображение не загрузилось, JavaScript показывает подпись «Изображение недоступно». Имя, показатели и ссылка артиста продолжают работать. Без JavaScript браузер оставляет альтернативный текст изображения.

## Доступность

Интерфейс адаптируется к узкому экрану. Все основные действия доступны клавишами Tab, Shift+Tab и Enter; активный элемент отмечен контуром. Первая ссылка страницы позволяет перейти прямо к содержимому. Поля поиска и фильтры имеют подписи, таблица концертов — заголовки, изображения — альтернативный текст. Сообщения об обновлении передаются через область статуса для программ чтения с экрана. При включённом системном уменьшении движения плавные эффекты отключаются.

Эта документация описывает поведение приложения. Адрес публичного размещения следует проверять отдельно по результату фактического развёртывания.
